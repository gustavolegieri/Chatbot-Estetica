# Biblioteca curada — candidatas para aprovação

**Como usar este arquivo (leva ~30-45 min no total):**

1. Para cada uma das **24 pastas** abaixo, abra os 2 links de busca (Pexels + Unsplash) — eles já vêm **pré-filtrados por cor** e por termo de estilo em inglês.
2. Escolha **6 a 8 fotos** que visualmente batem com a paleta E o estilo da pasta.
3. Cole a URL direta da foto (a que abre o preview grande, não a de download) no bloco `APROVADAS` da pasta, uma por linha.
4. Quando terminar (parcial ou total), me devolve este arquivo — eu baixo apenas as aprovadas, subo pra `public/assets/library/{pasta}/`, gero o `manifest.json`, e implemento o runtime.

**Não preciso das 24 pastas de uma vez.** Se aprovar 4-5 pastas já dá pra começar a validar o fluxo com essas paletas. As pastas restantes caem no fallback de API até você completar.

**Regra de ouro:** se bater dúvida se uma foto tem a cor certa, **descarta**. Uma pasta com 6 fotos certas é infinitamente melhor do que 8 com 2 duvidosas — o hash vai rotacionar dentro do que você aprovou.

**Licença:** Pexels e Unsplash são royalty-free para uso comercial sem atribuição obrigatória. Ainda assim eu vou salvar o crédito do fotógrafo no `manifest.json` de cada pasta.

## Depois que você me devolver este arquivo

1. Faço `curl` das URLs aprovadas, salvo em `public/assets/library/{pasta}/01.jpg`…`0N.jpg`.
2. Gero `manifest.json` por pasta com `{ files: [...], credits: [...] }`.
3. Implemento `src/lib/libraryPicker.ts` (hash determinístico) e refatoro `SmartSectionImage.tsx`.
4. Atualizo os edge functions Pexels/Unsplash para aceitar `color` nativo (Fase 2).
5. Rodo os 3 diagnósticos de teste via Playwright e mando os prints.
